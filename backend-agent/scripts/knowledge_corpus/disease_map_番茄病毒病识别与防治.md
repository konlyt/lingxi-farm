# 番茄病毒病（黄化曲叶与花叶）识别与防治
番茄病毒病主要有黄化曲叶病毒病（TY）与花叶病毒病（ToMV/TMV）两型，均系统侵染、一旦显症难以治愈，防治核心是"防虫截传 + 提前钝化"。
一、黄化曲叶病毒病。由烟粉虱传播的双生病毒。
识别要点：新叶黄化、叶片边缘上卷变厚变脆、植株矮化停滞，生长点簇生；结果期染病则坐果少、果实小而不转色。
发生条件：烟粉虱（B 型/Q 型）是唯一有效传毒介体，虫口密度大、带毒率高时暴发；夏秋高温期烟粉虱活跃，育苗和定植初期最危险。
防治：选用抗 TY 品种是根本；育苗棚和定植后全程 40–60 目防虫网 + 黄板诱杀烟粉虱，发现虫即治（螺虫乙酯、双丙环虫酯等，安全间隔期以标签为准）；拔除显症中心株并带出棚外销毁；发病初期可喷施氨基寡糖素、香菇多糖等钝化剂缓解，配合叶面肥促壮。
二、花叶病毒病。由机械接触与汁液传播（嫁接、整枝打杈、蚜虫传毒）。
识别要点：叶片呈黄绿相间花叶、轻微皱缩或蕨叶畸形，植株一般不严重矮化，果实出现斑驳或坏死条斑。
发生条件：农事操作交叉感染是棚内主要扩散方式；蚜虫发生重时传播快。
防治：种子消毒（10% 磷酸三钠浸种 20 分钟后清水洗净）；操作前后用肥皂水或牛奶蘸手、病健株分开管理；及时治蚜；喷施氨基寡糖素/宁南霉素钝化病毒并增施锌肥提高耐病性。
【用药注意】病毒病"治虫即治病"，防虫不到位则一切药剂收效甚微；显症重株无治疗价值，应及早清除。
