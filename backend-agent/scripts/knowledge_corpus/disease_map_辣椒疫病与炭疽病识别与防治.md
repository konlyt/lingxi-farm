# 辣椒疫病与炭疽病识别与防治
一、辣椒疫病。真菌性病害（疫霉菌），露地雨季与大棚高湿期暴发性强、蔓延快，是辣椒毁灭性病害之一。
识别要点：茎基部或分叉处出现水浸状暗绿色病斑，后缢缩变黑褐色，植株上部萎蔫青枯倒伏；叶片病斑边缘不清晰、软腐状；果实染病从蒂部开始软腐，表面可生稀疏白霉。剖开病茎维管束不变色（可与枯萎类区分）。
发生条件：高温高湿，雨后积水、大水漫灌、棚内闷湿时 3–5 天即可成片死亡；连作土壤带菌重。
防治：高垄/高畦栽培、膜下滴灌、严禁大水漫灌和雨后积水；与非茄科轮作 2 年以上。中心病株出现立即拔除并用甲霜·恶霉灵、烯酰吗啉、氟菌·霜霉威等灌根兼喷雾，封锁发病中心，5–7 天一次、连防 2–3 次；安全间隔期以标签为准。
二、辣椒炭疽病。真菌性病害，主要危害果实。
识别要点：果实表面初生水浸状褪绿凹陷圆斑，后扩大为同心轮纹状褐色凹陷斑，斑上轮生黑色小点（分生孢子盘），潮湿时溢出粉红色黏质孢子团；叶片偶生褐色轮纹斑。果实转色期与贮运期最易显症。
发生条件：高温高湿（25–30℃）、果面有水膜时侵染重；日灼伤、虫咬伤的果实更易感病——"先伤后病"。
防治：合理密植与整枝避免果实暴晒（防日灼为间接防病）；及时防治蛀果害虫减少伤口；发病初期用苯醚甲环唑、咪鲜胺、唑醚·代森联等喷雾，7–10 天一次、连防 2 次；安全间隔期以标签为准。
