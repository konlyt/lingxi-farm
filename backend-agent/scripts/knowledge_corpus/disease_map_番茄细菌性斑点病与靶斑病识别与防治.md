# 番茄细菌性斑点病与靶斑病识别与防治
一、番茄细菌性斑点病。病原为丁香假单胞菌番茄致病变种。
识别要点：危害叶、茎、果实。叶片初生水浸状深绿色小圆点，后变黑褐色坏死斑，周围常有黄色晕圈，病斑小而多、不穿孔；茎部和叶柄出现黑色条斑；青果上出现略隆起的黑色小斑点。湿度大时病部可见菌脓，这是与真菌性叶斑病区分的重要特征。
发生条件：低温高湿有利流行，气温 18–24℃、阴雨或喷灌溅水传播快；种子可带菌。
防治：选用无病种子并消毒（温汤浸种或药剂拌种）；避免喷灌改滴灌，减少叶面持水；农事操作在植株干燥时进行。发病初期选用铜制剂（氢氧化铜、王铜）或噻唑锌等细菌性药剂，5–7 天一次、连防 2–3 次；铜制剂避免高温时段使用以防药害，安全间隔期以标签为准。
二、番茄靶斑病（褐斑病）。真菌性病害。
识别要点：叶片病斑初为小型水浸状褪绿点，后扩展为中央色浅、具明显同心轮纹的坏死斑，整体轮廓大而形似靶标，易与早疫病混淆；区别在于靶斑病病斑更大、轮纹更宽平，且常在中上部叶片突发连片。
发生条件：高温高湿（25–30℃、多雨寡照）易发，通风不良的棚室夏季常见。
防治：加强通风降湿、及时清除病叶；发病初期选用唑醚·代森联、吡唑醚菌酯、苯醚甲环唑等喷雾，7–10 天一次、连防 2 次，轮换用药；安全间隔期以标签为准。
