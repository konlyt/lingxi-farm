# 番茄主要虫害防治方案（白粉虱、蚜虫、棉铃虫、斑潜蝇）
本方案覆盖大棚与露地番茄四种高发虫害，虫害防治以"早期监测 + 虫口压低 + 轮换用药"为原则。
一、白粉虱（温室白粉虱）。成若虫群集叶背刺吸汁液，分泌蜜露诱发煤污病，并可传播病毒。
监测与防治：棚内张挂黄色粘虫板（每亩 30–40 块）监测兼诱杀；风口设 40–60 目防虫网阻断迁入。发生初期用螺虫乙酯、呋虫胺、联苯菊酯等喷雾，重点喷叶背，5–7 天一次、连防 2–3 次；可与丽蚜小蜂释放配合（虫口低时放蜂，放蜂期间禁用广谱杀虫剂）。
二、蚜虫。群集嫩头嫩叶吸汁造成卷叶，传播多种病毒。
防治：黄板诱杀；发生初期用吡虫啉、啶虫脒、双丙环虫酯喷雾，重点喷心叶和叶背；安全间隔期通常 5–7 天，以标签为准。
三、棉铃虫。幼虫蛀食花蕾和果实，蛀孔大、粪便外露，转果危害损失重。
防治：成虫期设性诱剂或杀虫灯诱杀；抓住卵孵化盛期至幼虫 3 龄前（尚未蛀果）用药，选用氯虫苯甲酰胺、甲维盐、苏云金杆菌（Bt）等，5–7 天一次、连防 2 次；Bt 类避开高温强光时段施用。
四、番茄斑潜蝇（潜叶蝇）。幼虫潜入叶片上下表皮间蛀食，形成蜿蜒白色隧道，严重时叶片枯萎。
防治：悬挂黄色粘虫板诱杀成虫；及时摘除虫叶带出棚外深埋；发生初期用灭蝇胺（针对幼虫潜道）、阿维菌素等喷雾，7 天一次、连防 2 次。
【用药注意】杀虫剂重点喷施叶背与嫩头；同类作用机理药剂每季不超过 2 次以防抗性；采收前严格遵守安全间隔期（通常 3–7 天，以标签为准）。
