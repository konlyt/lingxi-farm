# 辣椒病毒病识别与虫害防治（茶黄螨、蚜虫、白粉虱）
一、辣椒病毒病。由蚜虫、粉虱、茶黄螨及机械接触传播的多种病毒（TMV/CMV/TEV 等）引起，症状多样。
识别要点：常见三型——花叶型：叶片黄绿斑驳、皱缩；黄化型：叶片整体黄化、脱落；坏死型：茎秆出现褐色坏死条斑、果实上有坏死环斑。植株顶端生长受抑、严重矮化，坐果少且畸形。
发生条件：高温干旱年份蚜虫粉虱繁殖快、传毒重；定植偏晚、苗期感病损失最大。
防治：种子消毒（10% 磷酸三钠浸种 20 分钟）；大棚覆盖防虫网 + 黄板全程治虫；喷施氨基寡糖素、宁南霉素钝化病毒，配合锌肥增强耐病性；显症重株及早拔除；整枝打杈健病株分开操作、工具消毒。
二、茶黄螨。体长仅 0.2 毫米、肉眼难见，嫩头受害误当"病毒病"的情况极多——鉴别要点：嫩叶小而僵直、叶缘下卷、叶背油亮有光泽，生长点节间缩短呈"秃尖"，与病毒病的黄化斑驳不同。
防治：虫害靠"治螨防螨"：发生初期用阿维菌素、乙螨唑、联苯肼酯等喷雾，重点喷嫩头嫩叶背面，5–7 天一次、连防 2–3 次（螨类易抗药，务必轮换）。
三、蚜虫与白粉虱。既直接危害又是病毒病传毒介体。
防治：黄板诱杀 + 防虫网；用吡虫啉、啶虫脒、双丙环虫酯、螺虫乙酯等，5–7 天一次、连防 2–3 次，重点喷叶背。
【用药注意】"治虫即防病毒"是辣椒植保主线；同类药剂每季不超 2 次防抗性；采收前遵守安全间隔期（一般 3–7 天，以标签为准）。
