# 黄瓜白粉病与枯萎病识别与防治
一、黄瓜白粉病。真菌性病害，棚室与露地均可发生。
识别要点：叶片正反两面初现白色近圆形粉状小霉斑（白粉层），后扩大连片布满叶面如撒白粉；后期粉层变灰白色并散生黑色小点，叶片枯黄卷曲。白粉霉层长在叶面正反两面、不出现水浸状病斑，是与霜霉病的直观区别。
发生条件：温暖干燥与高湿交替的环境反而不利结露、但利白粉——气温 20–28℃、湿度 45–75% 均可发病；通风差、光照弱、偏施氮肥植株贪青时重。
防治：选用抗病品种；平衡施肥增施钾肥；发病初期及早喷施醚菌酯、吡唑醚菌酯、氟菌唑、硫磺类（棚内可硫磺熏蒸）等，7–10 天一次、连防 2–3 次；白粉菌易抗药，唑类与甲氧基丙烯酸酯类轮换使用；安全间隔期以标签为准。
二、黄瓜枯萎病。真菌性土传病害（尖镰孢黄瓜专化型），重茬棚室危害大。
识别要点：典型表现是"萎蔫"——中午叶片萎蔫、早晚恢复，反复数日后全株枯死；茎基部纵裂、溢出琥珀色胶状物，湿度大时生粉红色霉层；维管束变褐（剖开茎秆可见），此为与根腐、生理性萎蔫区分的关键。
发生条件：土中病菌积累（连作 3 年以上重茬棚发病重）；地温 20–25℃、土壤高湿、根伤（移栽伤根、地下害虫咬根）时侵染快。
防治：预防为主——与水稻等轮作或嫁接栽培（黑籽南瓜砧木，防效最可靠）；定植前土壤消毒（棉隆/石灰氮闷棚）；发病初发现零星病株，用多抗霉素、恶霉灵、甲霜·恶霉灵灌根，每株 200–300 毫升，7 天一次、连灌 2–3 次；病株周围健株一并灌根保护。重病株无治疗价值应及时拔除并穴内消毒。
