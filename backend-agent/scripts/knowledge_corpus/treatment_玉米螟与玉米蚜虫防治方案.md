# 玉米螟与玉米蚜虫防治方案
一、玉米螟（亚洲玉米螟）。玉米第一大钻蛀性害虫，对应虫害识别主力数据集 IP102 中的核心害虫类群。
危害与识别：幼虫蛀茎、蛀穗——心叶期被害叶展开后呈一排排横列蛀孔（"花叶/排孔"是标志性识别特征）；穗期蛀食雌穗轴和茎秆，遇风折茎，直接影响产量。幼虫背部有 3 条纵线，老熟后在茎秆内越冬。
发生条件：一年 2–4 代，越冬代成虫 5–6 月始见；心叶期与穗期两个关键危害窗口；上代虫源基数大、气温高世代重叠时重。
防治：越冬幼虫羽化前处理秸秆（粉碎还田、沤肥或封存）压低虫源；成虫期设性诱剂、杀虫灯诱杀。化学防治抓住两个窗口：心叶末期（心叶丛出现排孔、雄穗将露）用氯虫苯甲酰胺颗粒剂丢心，或甲维盐、苏云金杆菌（Bt）对水灌心；穗期对花丝滴灌药液防蛀穗。Bt 与颗粒剂对天敌友好，优先选用。
二、玉米蚜虫。群集心叶、雄穗和雌穗花丝处吸汁，分泌蜜露诱发煤污、影响授粉灌浆，兼具传毒风险。
识别与条件：雄穗抽出至散粉期为危害高峰；干旱少雨年份重，"蜜露反光、蚂蚁上穗"是田间直观信号。
防治：蚜量达标（抽雄期 10% 植株百株蚜量超 5000 头）时，用吡虫啉、啶虫脒等喷雾，重点喷穗部；天敌（瓢虫、草蛉、蚜茧蜂）数量大时优先保护天敌，减少用药。
【用药注意】玉米为高秆作物，喷药注意人员防护与相邻蜜源作物安全；安全间隔期一般 21–28 天，以标签为准。
