# 番茄灰霉病识别与防治
适用作物：番茄（大棚冬春茬高发）。类型：真菌性病害，病原为灰葡萄孢菌。
【识别要点】主要危害花、果实、叶片和茎。果实染病多从残留的花瓣、花萼或柱头开始，出现水浸状软腐，表面密生灰褐色霉层；叶片病斑呈"V"字形向内扩展，有深浅相间的轮纹；茎部染病易折断。潮湿时病部产生大量灰色孢子粉，抖动可见烟雾状扩散。
【发生条件】低温高湿是主要诱因：气温 15–23℃、相对湿度 90% 以上持续阴雨寡照时最易流行；大棚通风不良、浇水后未放风、植株过密、残花不摘除均加重发病。
【防治方案】农业防治：控制棚内湿度是首位——晴天上午浇水、浇水后及时通风排湿；及时摘除残花、病叶病果并带出棚外销毁；合理密植，改善通风透光。物理防治：棚内悬挂臭氧/紫外线辅助消毒设备（如有）；通风口设防虫网减少携带传播。化学防治：发病初期选用腐霉利、异菌脲、嘧霉胺、啶酰菌胺等药剂喷雾或烟剂熏棚，7–10 天一次、连防 2–3 次，注意轮换用药防抗性；药剂安全间隔期通常 3–7 天，以所用产品标签为准。
【用药注意】灰葡萄孢易产生抗药性，同一作用机理药剂每季不超过 2 次；棚室烟剂熏棚后须通风后方可进入；采收前严格遵守安全间隔期。
