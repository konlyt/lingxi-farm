# 黄瓜灰霉病识别与防治
适用作物：黄瓜（冬春茬大棚高发）。类型：真菌性病害，病原为灰葡萄孢菌（与番茄灰霉病同源）。
【识别要点】多从开败的花器开始侵染，花瓣枯萎后长出灰霉再向瓜条蔓延——瓜条脐部先出现水浸状软腐、表面生灰褐色霉层，"烂花烂瓜头"是典型特征；叶片多从落花黏附处发病，形成大形枯斑有轮纹；茎蔓节部染病易折断。
【发生条件】低温高湿：气温 15–23℃、相对湿度 90% 以上、寡照结露重时流行快；冬春大棚放风不足、浇水过勤、残花不清除是主要诱因。
【防治方案】农事核心是"控湿 + 除残花"：晴天上午膜下浇水并放风排湿；每天摘瓜顺带摘除萎蔫花瓣病瓜并带出棚外；合理密植增强通风。化学防治与番茄灰霉病共用药剂体系：腐霉利、异菌脲、嘧霉胺、啶酰菌胺、氟唑菌酰胺类，喷雾或烟剂熏棚，7–10 天一次、连防 2–3 次；点片发生阶段可只喷发病中心及周边，减少用药量。
【用药注意】灰霉极易抗药，同类药剂每季不超 2 次并轮换机理；幼瓜期对药剂敏感，避开盛花当日高温施药；采收前遵守安全间隔期（一般 3–7 天，以标签为准）。
