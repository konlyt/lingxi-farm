# 黄瓜主要虫害防治方案（蓟马、蚜虫、白粉虱）
本方案覆盖棚室黄瓜三种高发虫害，统一原则：防虫网物理阻隔 + 粘板监测诱杀 + 早期压低虫口 + 轮换用药。
一、瓜蓟马（黄蓟马/棕榈蓟马）。成若虫挫吸嫩梢、花和幼瓜汁液；嫩叶皱缩变小、生长点萎缩，幼瓜出现木栓化银灰色疤痕甚至畸形脱落——"瓜面起锈斑"是标志。
防治：蓟马趋蓝，张挂蓝色粘虫板（每亩 30–40 块）监测兼诱杀；风口 40–60 目防虫网。用药选乙基多杀菌素、螺虫乙酯、联苯菊酯等，傍晚施药效果好（蓟马昼伏夜出、多藏于花内和叶背），5–7 天一次、连防 2–3 次。
二、蚜虫（瓜蚜）。群集嫩头吸汁致卷叶，分泌蜜露诱发煤污，兼传病毒病。
防治：黄板诱杀；用吡虫啉、啶虫脒、双丙环虫酯喷雾，重点喷嫩头与叶背；安全间隔期一般 5–7 天，以标签为准。
三、白粉虱。刺吸致叶片褪绿、蜜露诱发煤污并传毒，棚内周年繁殖。
防治：黄板诱杀 + 防虫网；用螺虫乙酯、呋虫胺、联苯菊酯等喷雾，重点喷叶背，5–7 天一次、连防 2–3 次；虫口低时可配合释放丽蚜小蜂（放蜂期禁广谱杀虫剂）。
【用药注意】三虫均繁殖快、易抗药：同一作用机理药剂每季不超过 2 次；喷药务必覆盖叶背与花器；若有蜜蜂授粉，花期禁用对蜂高毒药剂（如新烟碱类部分品种），并闭棚熏蒸后充分通风再放蜂；采收前遵守安全间隔期。
